# PROHLADA / Danchobeatz - Official Artist Website

## 📝 О проекте

Официальный сайт для PROHLADA (казахстанского исполнителя) и Danchobeatz (музыкального продюсера/битмейкера). Платформа служит единым цифровым хабом для аудитории артиста и артистов, ищущих качественные инструменталы для коллабораций.

**Слоган:** «PROHLADA — голос эмоций, а Danchobeatz — звук, который остаётся в памяти».

Сайт отражает внутреннюю эстетику исполнителя: искренность, преодоление трудностей и мелодичный саунд.

## 🎨 Дизайн система и Техническое задание (UX/UI)
- **Цветовая палитра:** Черный, Белый/Светло-Серый с текстурой мятой бумаги, Акцентный Красный (#b51b1f или аналог).
- **Типографика:** Тяжелый брутальный Гротеск (заголовки) + строгий гротеск без засечек (контент).
- **Стилистика:** Minimal, Grunge, Brutalism.

## 🎵 Интеграция Музыки & Аудио (Критически важно!)
Аудио-треки интегрированы так, чтобы сохранить On-Platform Streams:
1. Прямая интеграция `iframe` виджетов из Яндекс Музыка и Spotify на стороне сайта.
2. Система Smart Links (Bandlink/Linkfire) привязанная к CTA-кнопкам («Слушать везде»).
3. Блок **Beat Store**: (если есть) интеграция через iFrame официального HTML5-плеера BeatStars для автоматизированной покупки битов.

## 🗺 Структура страниц (One-page/Лендинг)
1. **Hero** — Анимированный текстурный фон, лого, кнопки-ярлыки "Музыка" / "Биты".
2. **Releases** — Грид-каталог с карточками последних релизов («Аминь», «Ты мой свет» и др.). 
3. **Producer / Beat Store** — Интерактивный плеер битов от Danchobeatz и блок Credits с упоминаниями коллабораций (Mr Lambo, Jamik, BALLER, и т.д.).
4. **About** — Секция с официальной биографией, отражающая двойную творческую личность (MC + Битмейкер).
5. **Contact/Footer** — Полный каталог официальных социальных ссылок (VK, Spotify, Telegram, TikTok, YouTube).

## 🚀 Стек технологий (Рекомендуемый)
- **Frontend-фреймворк:** React / Next.js (для быстрой загрузки, превосходного SEO артиста в поисковиках).
- **Стилизация:** Tailwind CSS или SCSS (легкое создание сложных ховер-анимаций на кнопках под бренд артиста).
- **Анимации:** GSAP / Framer Motion (для появления обложек, мягкого параллакса фоновой бумаги при скролле).
